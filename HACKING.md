## Referring to GitHub issues within commit message

https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/autolinked-references-and-urls#issues-and-pull-requests

- How to refer to issues in commit messages:
  - `#5` #5
  - `GH-5` GH-5
  - `gh-5` gh-5
- How to refer to commits in issue comments:
  - `b355054` b355054
